# Contributing

This is a personal study project, so outside code contributions aren't solicited. Issues are welcome:

- a question about a design or a decision;
- a challenge to a decision record, ideally with the evidence that would change it (each record says what that would be);
- a correction: a wrong number, a broken link, a misread source.

If you do open a pull request, it's read, but it may be closed in favour of the maintainer making the change, because the point of the project is for the maintainer to do the work.

The conventions for changes are in [AGENTS.md](AGENTS.md).
